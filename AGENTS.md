# AGENTS.md

Next.js site for the POLYMAZE robotics competition. See `README.md`.

- Install and run: `npm install`, `npm run dev`. Also `npm run build` and `npm run lint`.
- Routes live in `src/app`: `polymaze`, `aboutus`, `participate`, `faq`, `testimonies`, `register`.
- Registration talks to Supabase. Keys come from environment variables, never commit them.
